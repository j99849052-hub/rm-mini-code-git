# 机甲杯底盘 M1 速度闭环

2026-11-28 单轮基线。右后轮 M1 已完成实物验证。工程使用 STM32F103C8T6、CubeMX、Keil 和亚博四路电机驱动板。

## 当前实现

- STM32 用 TIM4 的 PB6、PB7 直接读取 M1 的 A/B 相编码器信号。主循环约每 100 ms 取一次样，按车轮每转一圈 2464 个计数换算 RPM。
- STM32 调用 `WheelPidUpdate()` 计算驱动值。`wheel1PIDState` 保存 M1 的积分、上次误差、有效标志和上次输出，供下一次计算使用。
- STM32 通过 USART2 发送 `$pwm` 给亚博驱动板。当前 M1 占命令第一路，另外三路置零。目标转速归零时清除 M1 的 PID 状态并发送零驱动值。
- 本版参数为 Kp = 1.0、Ki = 0.7、Kd = 0.0，驱动值限幅为 ±200。台架上曾观察到目标 100 RPM、实际约 84 RPM、`OUT = 200`。本次留档记录单轮闭环功能通过，上限与转速跟踪的复测另行安排。

## 排除和比较过的方案

- 早期用驱动板串口上报的 `$MAll` 计数换算转速，由 STM32 计算 PI 后发 `$pwm`。台架出现过速度一冲一慢、计数偶发反号，固定驱动值试转时也观察到反馈差异。资料包提供了主控端通信示例，驱动板内部采样、上报和 PWM 处理缺少可调试源码，现象的根因尚未确认。这条串口计数反馈路线已排除，本版反馈改由 TIM4 直读。
- 另做过板载速度闭环对照，STM32 发 `$spd`，驱动板计算速度环，STM32 读取 `$MSPD`。底盘项目选用由 STM32 实现速度环的路线，亚博驱动板执行 `$pwm`。

## 打开工程

- CubeMX 打开 [rm mini uart test.ioc](rm%20mini%20uart%20test.ioc)。
- Keil 打开 [rm mini uart test.uvprojx](MDK-ARM/rm%20mini%20uart%20test.uvprojx)。本机基线使用 ARM Compiler 6.24 和 STM32F1xx_DFP 2.4.1。
- [main.c](Core/Src/main.c) 包含测速、PID 和串口输出。原工程对应版本的 Keil 编译结果为 0 错误、0 警告。
